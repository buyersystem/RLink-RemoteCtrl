# RLink 核心源码阅读指南

本页是人工维护的架构入口，用来回答“从哪里开始读”。类、函数和成员的完整清单由同目录下的自动分册提供。

> 当前实现已不再使用 `.inc` 切片。大型类的公开接口与共享状态放在 `.h` 中，实现按职责拆成 `ClassName.Topic.cpp`。阅读时先看头文件，再追到对应主题实现。

## 先记住三层边界

1. **界面层**：`src/apps/controller`。处理 Qt 窗口、页面、用户操作和状态展示，不应自己实现会话协议。
2. **会话业务层**：`src/apps/remote` 与 `src/core`。编排 direct/room 会话、媒体、输入、文件和剪贴板，并向界面发布快照。
3. **传输与平台层**：`src/signaling`、`src/webrtc`、`src/protocol` 和 `src/platform/win`。分别负责 WSS 信令、PeerConnection/DataChannel、二进制协议和 Windows 采集/输入/编解码。

服务端在 `src/server`，与客户端共享的是消息约定，不是客户端运行时对象。

## 1. 启动、登录与更新

- [RemoteCProductMain.cpp](../src/apps/remote/RemoteCProductMain.cpp)：程序入口，创建 `QApplication`、读取启动配置、分流自测参数，然后启动应用协调器。
- [RemoteCApplicationCoordinator.h](../src/apps/remote/RemoteCApplicationCoordinator.h) / [实现](../src/apps/remote/RemoteCApplicationCoordinator.cpp)：管理启动窗口、Logto 认证、主窗口生命周期和统一退出。
- [SoftwareUpdateController.h](../src/apps/update/SoftwareUpdateController.h) / [实现](../src/apps/update/SoftwareUpdateController.cpp)：获取更新清单，解析版本、发布说明和多个下载镜像，并启动独立更新器。
- [RLinkUpdaterMain.cpp](../src/apps/update/RLinkUpdaterMain.cpp)：独立更新进程，完成下载、SHA-256 校验、替换、失败回滚和重启。

查更新窗口文字时，先看更新清单里的 `version`、`summary` 和 `releaseNotes`；窗口展示逻辑再从 `SoftwareUpdateController` 追到主窗口。

## 2. 主窗口与远程会话窗口

- [ControllerMainWindow.h](../src/apps/controller/ControllerMainWindow.h)：主窗口的公开接口、会话快照入口和共享状态。
- `ControllerMainWindow.*.cpp`：按 `AppShell`、`Ui`、`Session`、`Room`、`Media`、`Diagnostics`、`SettingsPage` 等职责拆分。如果只知道按钮或页面名，先在 [应用层：主界面与远程会话窗口](01_apps_controller.md) 搜索。
- [RemoteSessionBinding.h](../src/apps/controller/RemoteSessionBinding.h)：界面持有的会话绑定，区分 direct 会话和 room pair。
- [RemoteSessionWindow.h](../src/apps/controller/RemoteSessionWindow.h)：监控窗口总接口；`RemoteSessionWindow.*.cpp` 分管生命周期、布局、显示、媒体、会话动作和传输进度。
- [RemoteDesktopCanvas.h](../src/apps/controller/RemoteDesktopCanvas.h) / [实现](../src/apps/controller/RemoteDesktopCanvas.cpp)：远程画面呈现、坐标换算、本地输入采样和远端光标合成的核心边界。

## 3. 会话接口、快照与主引擎

- [ISessionEngine.h](../src/core/ISessionEngine.h)：界面面向的会话命令和快照观察者接口，是查看“UI 能做什么”的第一入口。
- [SessionEngineTypes.h](../src/core/SessionEngineTypes.h)：包含 `SessionEngineSnapshot` 等跨线程传向界面的状态模型。
- [InProcessSessionEngine.h](../src/apps/remote/InProcessSessionEngine.h)：主会话引擎的公开接口与所有权边界。
- `InProcessSessionEngine.Lifecycle.cpp`：启动、停止和 generation 失效。
- `InProcessSessionEngine.Direct*.cpp`：direct 连接、媒体、数据通道和回调。
- `InProcessSessionEngine.Room*.cpp` 与 `RoomPair*.cpp`：房间命令、pair 状态、媒体路由和可靠数据分发。
- `InProcessSessionEngine.ScreenShare.cpp`、`Audio.cpp`、`Camera.cpp`：本地媒体源与发送关系。

排查异步错误时，同时检查对象所有权、回调所在线程、generation/sequence 以及断线后的过期回调。

## 4. 认证与 WSS 信令

- [AuthManager.h](../src/auth/AuthManager.h)：登录、令牌恢复/刷新和登出协调。
- [ISignalingClient.h](../src/signaling/ISignalingClient.h)：客户端信令抽象。
- [QtWebSocketSignalingClient.h](../src/signaling/QtWebSocketSignalingClient.h)：WSS 客户端公开接口；`Connection`、`Dispatch*`、`Negotiation`、`RoomCommands`、`Recovery` 等 `.cpp` 按消息方向与业务分组。
- [SignalingJsonCodec.cpp](../src/signaling/SignalingJsonCodec.cpp)：信令 JSON 编解码边界。

## 5. 信令服务器与设备身份

- [SignalServerMain.cpp](../src/server/signaling/SignalServerMain.cpp)：服务端参数、TLS/ICE/认证配置和事件循环入口。
- [SignalServer.h](../src/server/signaling/SignalServer.h)：服务端公开接口；`SignalServer.Internal.h` 保存内部状态。
- `SignalServer.Authentication.cpp`、`Connection.cpp`、`OwnedDevices.cpp`、`LegacySession.cpp`：客户端认证、设备注册和 direct 会话。
- `SignalServer.RoomMembership.cpp`、`RoomPairs.cpp`、`RoomLeases.cpp`、`RoomState.cpp`：房间成员、pair、控制/共享租约和广播快照。
- [IdentityStore.h](../src/server/persistence/IdentityStore.h) / [实现](../src/server/persistence/IdentityStore.cpp)：SQLite 设备身份持久化。设备码稳定性问题优先检查硬件指纹与该表的映射更新。

## 6. WebRTC、采集、编解码与输入

- [LibWebRtcSession.h](../src/webrtc/LibWebRtcSession.h)：PeerConnection 会话的公开接口；`Lifecycle`、`Negotiation*`、`DataChannels`、`VideoSlots`、`StatsClose` 等 `.cpp` 分管实现。
- [WindowsDesktopCaptureSource.h](../src/platform/win/WindowsDesktopCaptureSource.h)：屏幕采集调度与帧输出。
- [DxgiNativeDesktopCapturer.h](../src/platform/win/DxgiNativeDesktopCapturer.h)：DXGI 原生纹理采集路径。
- `MfD3D11H264Encoder*`、`Ffmpeg*H264*`：Media Foundation 与 FFmpeg/x264 编解码后端。
- [WindowsInputExecutor.h](../src/platform/win/WindowsInputExecutor.h)：校验并注入远端鼠标、键盘输入。
- [WindowsCursorMonitor.h](../src/platform/win/WindowsCursorMonitor.h)：采集本地光标形状和位置供远端合成。

## 7. 文件、剪贴板与二进制协议

- [FileTransferController.h](../src/apps/remote/FileTransferController.h)：文件传输总接口；`Commands`、`Chunking`、`Send`、`Receive`、`Reliability`、`Worker` 等 `.cpp` 分管命令、分块、重传和后台 I/O。
- [ClipboardController.h](../src/apps/remote/ClipboardController.h) / [实现](../src/apps/remote/ClipboardController.cpp)：剪贴板同步策略、状态和传输边界。
- `src/protocol`：输入、光标、屏幕控制、文件、剪贴板和房间成员控制的编解码。修改协议时要同时检查发送端、接收端和版本兼容。

## 8. 构建文件怎样对应源码

- [CMakeLists.txt](../CMakeLists.txt)：顶层工程、依赖路径、C++20 与 `/MD` 策略。
- [cmake/targets.cmake](../cmake/targets.cmake)：权威的 target 与源文件列表。新增 `.cpp/.h` 时需要在这里纳入对应 target。
- [CMakePresets.json](../CMakePresets.json)：当前 Windows x64 configure/build 预设。
- [Windows 源码构建指南](../Windows源码构建指南.md)：从依赖准备到命令行和 Visual Studio 打开方式的完整说明。

## 9. 维护规则

1. 新增、删除或重命名 C/C++ 文件后，在仓库根目录运行 `./tools/Generate-SourceSymbolReference.ps1`。
2. 自动分册不手工改；职责边界变化时才更新本页。
3. 导航用于定位，实际行为仍以当前源码、调用方和运行时日志为准。
